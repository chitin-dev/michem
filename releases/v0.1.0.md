# Michem v0.1.0

Initial public release of Michem, a Typst package for drawing chemical
structures, reaction routes and authored electron-flow mechanisms. Chemical
layout and depiction are powered by Chitin through a precompiled WebAssembly
plugin.

## Highlights

- Draw molecules from SMILES or authored molecular graphs, with automatic
  layout, stereochemistry, rings, charges and named atom anchors.
- Compose automatic reaction routes with `reaction-route`, `reaction-stage` and
  `reaction-step`. The templates handle connected chains, branches, joins,
  wrapping and circular layouts, and place plus signs, connectors, conditions
  and compound names.
- Attach local atom or bond highlights to compounds, including peripheral
  reactants and products in circular routes.
- Build annotated mechanisms with `mechanism`, `mechanism-data` and
  `mechanism-panels`: molecule occurrences, highlights, lone pairs, electron
  dots, curved electron arrows and reaction connectors.
- Use exact circular arcs or explicit Bezier curves for electron arrows, with
  optional bounded, obstacle-aware routing between fixed chemical endpoints.
- Inspect atom IDs with `style(debug: true)` to select highlight and arrow
  references.
- Embed molecules in CeTZ canvases through `michem.cetz.molecule` and
  `michem.cetz.reaction`, with named atom anchors.

## Installation

```typst
#import "@preview/michem:0.1.0" as michem
```

The package requires Typst 0.14.0 or newer. The WebAssembly plugin is included;
no Rust toolchain is needed by package users. Named fonts must be available to
Typst through system fonts, the web project or `--font-path`.

## Documentation

- `docs/manual.typ` contains signatures, coordinate systems, defaults and
  routing limits.
- `examples/quick-start.typ` is a compact introduction.
- `examples/gallery.typ` collects molecular, route and mechanism examples.
- `examples/organic/` contains longer teaching examples.

## Scope and limitations

Michem draws supplied chemical facts; it does not predict reactions, infer
lone-pair counts or balance equations. Circular routes support one ring with
neighboring stages. Automatic electron-arrow routing is bounded and reports an
error when no clear candidate is found. Increase spacing or adjust the authored
geometry in that case.
